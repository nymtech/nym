<Callout type="warning">
The Explorer API is retired and `explorer.nymtech.net` no longer answers. Use the [Node Status API](/apis/ns-api) instead, which provides the same data and more.
</Callout>

The Explorer API was the backend for the first version of the [Mixnet Explorer](https://nym.com/explorer). The service was removed from the Nym codebase in [#5701](https://github.com/nymtech/nym/pull/5701).
