---
title: "Well-known trust-anchor URLs"
---

Alongside the nym-api, nyxd, and contract addresses described in [The network details model](snippet:nym/specifications/nym-network/technical-details/discovery-urls/network-details-model/intro), `common/network-defaults` carries a small set of fixed, non-nym-api URLs that a client or signer fetches for specific trust decisions. This document lists them and points to the components that own the depth for each; discovery-urls only owns the fact that these constants live in the same table as the rest of the network's identity.
