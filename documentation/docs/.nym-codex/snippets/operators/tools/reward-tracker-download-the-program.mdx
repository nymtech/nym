### Download the program [#reward-tracker-download-the-program]

There are two options how to get `node_rewards_tracker.py`

**Download the program, using `curl`**

- Open terminal and navigate to your destination directory and run:

```sh

curl -L "https://raw.githubusercontent.com/nymtech/nym/refs/heads/develop/scripts/rewards-tracker/node_rewards_tracker.py" -o node_rewards_tracker.py
```

**Pull / clone `nymtech/nym` repository**

- Open terminal and navigate to where you want to have `nym` repostiry and run:

```sh
git clone https://github.com/nymtech/nym
```

- Copy `node_rewards_tracker.py` from `nym/scripts/rewards-tracker/node_rewards_tracker.py` to your destination
