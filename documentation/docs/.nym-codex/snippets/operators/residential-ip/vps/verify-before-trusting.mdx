### Verify before trusting [#verify-before-trusting]

Cross-check the assigned IP against [ipinfo](https://ipinfo.io), [ipapi.is](https://ipapi.is), [MaxMind](https://www.maxmind.com/en/geoip-demo) and a fraud score ([IPQualityScore](https://www.ipqualityscore.com/) or [Spur](https://spur.us/)) before counting it as residential. See [how to verify classification](snippet:nym/operators/residential-ip/index/how-to-verify-classification).
