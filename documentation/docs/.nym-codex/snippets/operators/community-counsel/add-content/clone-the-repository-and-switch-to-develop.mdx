### Clone the repository and switch to `develop` [#clone-the-repository-and-switch-to-develop]

Clone `nymtech/nym` repository or pull in case you already have it and switch to `develop` branch

- Clone the repository
```sh
git clone https://github.com/nymtech/nym.git
```

- Go to the directory nym
```sh
cd nym
```

- Switch to branch develop and update the branch
```sh
git checkout develop
git pull origin develop
```
