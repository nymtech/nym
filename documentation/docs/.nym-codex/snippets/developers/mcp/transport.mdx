## Transport [#transport]

Streamable HTTP: a single endpoint that accepts [JSON-RPC 2.0](https://www.jsonrpc.org/specification) over `POST`. The server is stateless, so there is no session to establish. A request must advertise both response content types in its `Accept` header, or the server replies `406`:

```text
Accept: application/json, text/event-stream
```

The reply comes back as a Server-Sent Events frame (`event: message` / `data: {...}`) carrying the JSON-RPC result.
