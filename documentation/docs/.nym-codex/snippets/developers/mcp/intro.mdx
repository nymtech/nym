---
title: "MCP Server"
---

The Nym docs [MCP](https://modelcontextprotocol.io) server lets an AI coding agent search the Nym documentation and read live network state as structured tool calls. You do not paste doc links, and the agent does not guess at API shapes. Point it at one URL:

```text
https://nym.com/docs/api/mcp
```

It exposes two kinds of tool:

- **Documentation retrieval:** semantic search over the docs corpus, returning ranked excerpts with deep-link URLs back into these pages.
- **Live network data:** bonded node counts, gateway health, token supply and chain status, read from the Nym APIs at call time.

Use the live tools when a static `llms.txt` is not enough. An agent can ask "is gateway X bonded, and what is its performance score right now?" and get a current answer. A static file has only the state at build time.
