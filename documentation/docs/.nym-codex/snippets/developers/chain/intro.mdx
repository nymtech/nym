---
title: "Interacting with the Nyx blockchain"
---

Nyx is the Cosmos-SDK blockchain that underpins Nym. It holds the NYM token and the mixnet smart contracts (node bonding, rewarding, and the directory). There are several ways to query Nyx and submit transactions to it.

For smart-contract access from TypeScript, see [`@nymproject/contract-clients`](https://www.npmjs.com/package/@nymproject/contract-clients), covered under [Smart Contracts](snippet:nym/developers/typescript/smart-contracts/intro) in the TypeScript SDK.
