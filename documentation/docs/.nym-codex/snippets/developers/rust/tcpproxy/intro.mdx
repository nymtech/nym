<Callout type="error">
This module is unmaintained. The TcpProxy is no longer actively developed in favour of the [Stream module](snippet:nym/developers/rust/stream/intro), which provides `AsyncRead + AsyncWrite` channels directly over the Mixnet without the localhost TCP socket layer. Existing users should plan to migrate. The module will continue to work but will not receive new features or bug fixes.
</Callout>

<Callout>
Requires the `tcp-proxy` feature, which is on by default. With `default-features = false`, add `features = ["tcp-proxy"]` (this also enables `fs-storage` and `client-pool`); the `nym-proxy-server` and `nym-proxy-client` binaries need `cli`. See [Installation](/developers/rust/importing#feature-flags).
</Callout>

`NymProxyClient` and `NymProxyServer` proxy TCP traffic through the Mixnet. Both run in a background thread and expose a configurable `localhost` socket that callers read and write to like any other TCP connection. The Stream module replaces this pattern with multiplexed channels on a single client and no localhost socket layer.

> Non-Rust/Go developers can use the [standalone binaries](snippet:nym/developers/tools/standalone-tcpproxy/intro) instead.
