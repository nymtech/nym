## Examples [#examples]

Runnable examples in [`sdk/rust/nym-swizzle/examples/`](https://github.com/nymtech/nym/tree/develop/sdk/rust/nym-swizzle/examples). Each is self-contained; read the `//!` doc comments at the top of each file for the reasoning behind it.

```sh
cargo run -p nym-swizzle --example <name>
```

| Example | Source | What it demonstrates |
|---|---|---|
| Delay a broadcast | [`delay_broadcast.rs`](https://github.com/nymtech/nym/blob/develop/sdk/rust/nym-swizzle/examples/delay_broadcast.rs) | Scheduling a broadcast after a sampled delay. Broadcast timing is a leak the destination reads directly: a wallet that sends the moment it reaches chain tip is correlatable with its own sync activity |
| Overlapping range fetch | [`fetch_blocks_overlapping.rs`](https://github.com/nymtech/nym/blob/develop/sdk/rust/nym-swizzle/examples/fetch_blocks_overlapping.rs) | Resuming a sync through overlapping, shuffled chunks, so the start height stops naming the resume point and stops chaining one session to the last |
| Poisson delays | [`poisson_sampling.rs`](https://github.com/nymtech/nym/blob/develop/sdk/rust/nym-swizzle/examples/poisson_sampling.rs) | Exponential inter-arrival times, the same construction the mixnet uses for its own cover traffic |
| Seeded determinism | [`seeded_vrf.rs`](https://github.com/nymtech/nym/blob/develop/sdk/rust/nym-swizzle/examples/seeded_vrf.rs) | A fixed 32-byte seed reproducing a byte-identical plan and delay sequence, for VRF-derived or otherwise reproducible schedules |
