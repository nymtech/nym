A manual upgrade brings [`nym-node`](snippet:nym/operators/nodes/maintenance/manual-upgrade/nym-node-upgrade) or [`validator`](snippet:nym/operators/nodes/maintenance/manual-upgrade/validator-upgrade) to the latest version in a few steps. If you prefer to automate the process, try to setup your flow with [Nymvisor](nymvisor-upgrade).
