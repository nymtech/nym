## Prerequisites [#prerequisites]

| Item | Requirement |
| :-- | :-- |
| Host | Same machine that runs (or will run) `nym-api`, Ubuntu 24.04 x86_64 recommended |
| Disk | Enough free space for a Nyx snapshot restore, at least 200GB, the more the better |
| Ports | 26656 open for P2P, 26657 and 1317 loopback only |
