## Reading the verdicts [#reading-the-verdicts]

- ✅ the property holds, subject to the condition in the cell text.
- ◐ partial: it holds against some observation, not all (see the
  per-configuration page).
- ❌ the property fails.

The "Fast" column is throughput, not privacy. The mixnet's mixing delays make it
slow. So bulk traffic belongs on dVPN, and only small, timing-sensitive requests
belong on the mixnet.
