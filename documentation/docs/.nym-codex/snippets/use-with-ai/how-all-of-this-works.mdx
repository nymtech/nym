## How all of this works [#how-all-of-this-works]

The Markdown files and `llms-full.txt` come from the docs build, in one pass over
the pages. The MCP server searches a shared semantic index, which each indexed Nym
repository updates from its own CI: the docs and the Nym source, and the NymVPN
client's code and docs.

Every search result carries a deep link to the section it came from. Any claim an
agent makes can be checked against the page behind it.

The MCP endpoint is open: no API key, no account. It embeds each incoming query at
Nym's expense and returns raw sections without generating anything, so the only
tokens you spend are your own agent's. See
[how search works](snippet:nym/use-with-ai/mcp/how-search-works) for the mechanism.

CI checks some facts in these pages against their sources in the code and the threat model. It does not check the explanations that people write. See [how these docs are checked](snippet:nym/about/how-these-docs-are-checked/intro).
