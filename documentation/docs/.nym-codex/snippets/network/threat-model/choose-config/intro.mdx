Which configuration you need falls out of the [threat
model](/network/threat-model), not from tool popularity. Decide **who you are
hiding from**, then read the row. Each verdict is P1 (identity) or P2 (request
linkability) against one [actor](snippet:nym/network/threat-model/actors/intro); the detail text
gives the condition. Click a configuration to see its path and full assessment.
