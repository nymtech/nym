## Building Nym [#building-nym]

Nym has two main codebases:

- the [Nym platform](https://github.com/nymtech/nym), written in Rust. This contains all of our code _except_ for the validators.
- the [Nym validators](https://github.com/nymtech/nyxd), written in Go.

> The build steps in [Prerequisites](snippet:nym/operators/binaries/building-nym/prerequisites) and [Download and build Nym binaries](snippet:nym/operators/binaries/building-nym/download-and-build-nym-binaries) build the main Nym platform code. **If you want to build and run a validator, [go here](../nodes/validator-setup) instead.**
