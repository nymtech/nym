## Preparation [#preparation]

We recommend to have installed all [the prerequisites](snippet:nym/operators/binaries/building-nym/prerequisites) needed to build `nym-node` from source including latest [Rust Toolchain](https://www.rust-lang.org/tools/install), **and** make sure to have [Go](https://go.dev/doc/install) installed. Go is necessary as the probe uses the `rust2go` FFI library to use `netstack` when making requests.
