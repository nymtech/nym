### Nym API `systemd` automation [#nym-api-systemd-automation]

Save the Nym API init service file as `/etc/systemd/system/nym-api.service` and run all commands with root permissions. The steps start at [Create an init service file](snippet:nym/operators/nodes/validator-setup/nyx-configuration/nym-api-create-an-init-service-file).
