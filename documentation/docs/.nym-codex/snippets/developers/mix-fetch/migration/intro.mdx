title: "Migrating from v1.x or v2.x"
aspect: design
aspect_review: true
---

If you're on v2, only [From v2 to v3](snippet:nym/developers/mix-fetch/migration/from-v2-to-v3) applies: v3 replaces the DNS options. If you're on v1, read all the migration steps. v2 is a clean break from v1. The package no longer ships a Go-WASM HTTP/TLS client or a SOCKS5-shaped Network Requester request; it routes through the shared [`mix-tunnel`](snippet:nym/developers/mix-tunnel/intro) and exits at an IPR. If you're starting fresh, you don't need the v1.x migration steps; see [mix-fetch](snippet:nym/developers/mix-fetch/intro).
