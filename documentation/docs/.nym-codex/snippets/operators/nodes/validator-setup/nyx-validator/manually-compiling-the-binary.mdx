### Manually compiling the binary [#manually-compiling-the-binary]

The codebase for the Nyx validators is at [nymtech/nyxd](https://github.com/nymtech/nyxd). Compile it with:

```sh
git clone https://github.com/nymtech/nyxd.git
cd nyxd

# check releases for the latest version information
git checkout release/<NYXD_VERSION>

make build
```

You will then have a `nyxd` binary in `build/`. Test it runs:

```sh
./build/nyxd
```
