---
title: "Tools"
---

Standalone binaries for development and testing that don't require an SDK. Download or compile them and use them directly.

| Tool | Use case |
|---|---|
| [nym-cli](/developers/tools/nym-cli) | Command-line interface for interacting with the Nyx blockchain: querying state, submitting transactions, managing keys. An easier-to-use wrapper around `nyxd`. |
| [Diagnostic Tool](/developers/tools/diagnostic-tool) | Network diagnostic utility for troubleshooting connectivity issues. |
| [Standalone TcpProxy](/developers/tools/standalone-tcpproxy) | Pre-built binaries of the TcpProxy client and server for proxying TCP traffic through the Mixnet. The TcpProxy module is unmaintained; use the [Stream module](/developers/rust/stream) for new projects. |
