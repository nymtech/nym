---
title: "Nym Node"
---

NYM NODE is a tool for running a node within the Nym network. Nym Nodes containing functionality such as `mixnode`, `entry-gateway` and `exit-gateway` are fundamental components of Nym Mixnet architecture. Nym Nodes are ran by decentralised node operators.

To setup any type of Nym Node, start with either building [Nym's platform](snippet:nym/operators/binaries/building-nym/intro) from source or download [pre-compiled binaries](snippet:nym/operators/binaries/pre-built-binaries/intro) on the [configured server (VPS)](/operators/nodes/preliminary-steps/vps-setup) where you want to run the node. Your Nym Node will need to be bonded before it can be run. We recommend most users use the [Nym desktop wallet](/operators/nodes/preliminary-steps/wallet-preparation) for this.

**Read thoroughly [Minimum Requirement page](/operators/nodes) before you configure and run a `nym-node`!**
