## If none of this rules you out [#if-none-of-this-rules-you-out]

Start at [choose a defence](/network/threat-model/choose-config) to pick a
configuration from your threat model, then [the developer front
door](/developers) to map that configuration to a package.

Then read [planning an integration](snippet:nym/developers/integrating/intro) to decide which
of your endpoints go through the mixnet. That is a decision per endpoint, not
one switch.
