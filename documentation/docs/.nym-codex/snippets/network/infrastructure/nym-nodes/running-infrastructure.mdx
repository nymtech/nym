## Running infrastructure [#running-infrastructure]

<TimeNow />

The current deployment includes <Stat name="nodes" /> active nodes across <Stat name="locations" /> countries, operated by independent parties worldwide. This includes <Stat name="mixnodes" /> Mix Nodes and <Stat name="exit_gateways" /> Exit Gateways. Running a node requires meeting minimum hardware specifications, bonding NYM tokens as collateral, and maintaining high uptime for rewards.

For the hardware requirements, bonding, and setup steps, see the [node setup guides](/operators/nodes) in the operator documentation.
