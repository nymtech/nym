---
title: "Discovery URLs: Design and Rationale"
---

The discovery-URL design explains why network discovery in Nym is a static, versioned table rather than a runtime protocol, and how `common/network-defaults` (`nym-network-defaults`) sits relative to the rest of the workspace. Four companion documents cover [the data model](snippet:nym/specifications/nym-network/technical-details/discovery-urls/network-details-model/intro), [the bootstrap and override sequence](snippet:nym/specifications/nym-network/technical-details/discovery-urls/bootstrapping-and-overrides/intro), [the resilience behaviour](snippet:nym/specifications/nym-network/technical-details/discovery-urls/resilience-and-fronting/intro) built on top of it, and [the small set of additional well-known URLs](snippet:nym/specifications/nym-network/technical-details/discovery-urls/well-known-trust-anchors/intro) a client or signer resolves alongside nym-api and nyxd.
