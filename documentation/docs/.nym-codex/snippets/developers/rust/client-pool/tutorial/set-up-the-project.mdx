### Set up the project [#set-up-the-project]

```sh
cargo init nym-pool-demo
cd nym-pool-demo
```

Add dependencies to `Cargo.toml`:

```toml
[dependencies]
nym-sdk = "2.0.0"
nym-network-defaults = "2.0.0"
nym-bin-common = { version = "2.0.0", features = ["basic_tracing"] }
tokio = { version = "1", features = ["full"] }
```
