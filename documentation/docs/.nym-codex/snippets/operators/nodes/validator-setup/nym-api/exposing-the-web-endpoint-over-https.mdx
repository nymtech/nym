## Exposing the web endpoint over HTTPS [#exposing-the-web-endpoint-over-https]

It is recommended to expose the webserver over HTTPS using a webserver such as nginx. An example configuration is on the [Nyx & Nym API configuration page](snippet:nym/operators/nodes/validator-setup/nyx-configuration/nym-api-configuration). If you use a custom solution, ensure a permissive CORS policy by setting:

```sh
add_header 'Access-Control-Allow-Origin' '*';
```
