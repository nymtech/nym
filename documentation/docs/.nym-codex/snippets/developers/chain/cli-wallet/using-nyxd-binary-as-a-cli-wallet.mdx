### Using `nyxd` binary as a CLI wallet [#using-nyxd-binary-as-a-cli-wallet]
You can use `nyxd` as a minimal CLI wallet if you want to set up one or more accounts. Compile the binary as per the documentation, stopping after the [building your validator](snippet:nym/operators/nodes/validator-setup/nyx-validator/building-your-validator) step is complete. Then run `nyxd keys --help` to see how to set up and store keypairs for interacting with the Nyx blockchain.
