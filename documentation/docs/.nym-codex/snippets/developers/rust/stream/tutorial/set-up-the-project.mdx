### Set up the project [#set-up-the-project]

```sh
cargo init nym-echo
cd nym-echo
rm src/main.rs
```

Add dependencies to `Cargo.toml`:

```toml
[dependencies]
nym-sdk = "1.22.2"
nym-bin-common = { version = "1.22.2", features = ["basic_tracing"] }
tokio = { version = "1", features = ["full"] }
rand = "0.8"
```
