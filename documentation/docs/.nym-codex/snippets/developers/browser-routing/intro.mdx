---
title: "Routing a browser or WebView app"
---

To route a browser app through the mixnet, a web app catches requests that
bypass the mixnet, proves a request went through it, and blocks the direct path
with Content Security Policy. Some traffic no web app can route. A WebView host runs
the same web platform as a browser tab, so Capacitor, Cordova, WKWebView and
Android WebView are in scope.

Which endpoints to route, and the failure modes that are not specific to the
web runtime, are covered in
[planning an integration](snippet:nym/developers/integrating/intro).
