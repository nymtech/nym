---
title: "Discovery URLs: Design and Rationale"
---

This document covers why network discovery in Nym is a static, versioned table rather than a runtime protocol, and how `common/network-defaults` (`nym-network-defaults`) sits relative to the rest of the workspace. The four following documents cover the data model, the bootstrap and override sequence, the resilience behaviour built on top of it, and the small set of additional well-known URLs a client or signer resolves alongside nym-api and nyxd.
