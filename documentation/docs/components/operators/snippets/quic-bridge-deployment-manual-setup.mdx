The manual path does the same work as the script, by hand. Full reference: [nym-bridges README](https://github.com/nymtech/nym-bridges/blob/main/README.md).

<Steps>
###### Install the `nym-bridge` binary
- amd64 with glibc ≥ 2.34 (Ubuntu 22.04+, Debian 12+). Download the `.deb` from [nym-bridges releases](https://github.com/nymtech/nym-bridges/releases) and install it — it ships both `nym-bridge` and `bridge-cfg`:
```sh
dpkg -i nym-bridge_*_amd64.deb
```

###### Generate the bridge config
- Point `bridge-cfg` at your `nym-node` `config.toml`; this creates the QUIC transport and its key:
```sh
bridge-cfg --gen -n /root/.nym/nym-nodes/default-nym-node/config/config.toml -d /etc/nym -o /etc/nym/bridges.toml
```

###### Add the TLS and SSH entry transports
- Append both to `/etc/nym/bridges.toml`:
```toml
[[transports]]
transport_type = "tls_plain"
[transports.args]
listen = "[::]:4443"

[[transports]]
transport_type = "ssh_plain"
[transports.args]
listen = "[::]:4422"
```
- Mint keys for the new transports while keeping the existing QUIC key (note the `-i`):
```sh
bridge-cfg --gen -i /etc/nym/bridges.toml -n /root/.nym/nym-nodes/default-nym-node/config/config.toml -d /etc/nym -o /etc/nym/bridges.toml
```

<Callout type="warning" emoji="⚠️">
On an existing bridge, back up `/etc/nym` first and confirm the QUIC `id_pubkey` is unchanged afterwards. Regenerating it breaks every user relying on the old key.
</Callout>

###### Create and enable the service
```sh
cat > /etc/systemd/system/nym-bridge.service <<'EOF'
[Unit]
Description=Nym Bridge (QUIC/TLS/SSH entry)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
Environment=RUST_LOG=info
ExecStart=/usr/bin/nym-bridge --config /etc/nym/bridges.toml
Restart=on-failure
RestartSec=5
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now nym-bridge
```

###### Open the bridge ports with the Network Tunnel Manager
- Rerun NTM so the host opens the bridge ports (`udp/4443`, `tcp/4443`, `tcp/4422`):
```sh
curl -L https://raw.githubusercontent.com/nymtech/nym/refs/heads/develop/scripts/nym-node-setup/network-tunnel-manager.sh -o network-tunnel-manager.sh && \
chmod +x network-tunnel-manager.sh
bash network-tunnel-manager.sh configure_network_firewall
```
- Allow the same ports inbound in your provider's firewall / security group.

###### Validate
```sh
systemctl status nym-bridge.service
ss -lntup | grep nym-bridge
```

###### Restart `nym-node`
```sh
service nym-node restart && journalctl -u nym-node.service -f --all
```
</Steps>
