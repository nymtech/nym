## Nodes Account Top-up [#nodes-account-top-up]

Every `nym-node` client contains a mnemonic of a Nyx account, generated with node initialisation (first `run` command creating all configuration and data files). This mnemonic is located in `$HOME/.nym/nym-nodes/<ID>/data/cosmos_mnemonic`. **This is *not* the same account as the one used for bonding!**

Read more detailed explanation of the function of this client account [here](/operators/nodes/nym-node/bonding#fund-nym-node-client-nyx-account).

Operators can use [`nodes_account_topup.py`](https://github.com/nymtech/nym/blob/develop/scripts/nym-node-setup/auto-bond/nodes_account_topup.py) to top up a fleet of nodes with one command to a desired amount.
