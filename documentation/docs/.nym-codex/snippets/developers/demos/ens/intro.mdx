---
title: "ENS over the mixnet"
---

This demo does an ENS lookup (name to address to IPFS website) with [ethers.js](https://docs.ethers.org/v6/). Every network request goes through the Nym mixnet. The Ethereum RPC node and the IPFS gateway see the [IPR](/network/infrastructure/exit-services#ip-packet-router) exit's IP address, not yours, and your ISP cannot see which names or sites you reach. The trade-off is latency: every packet takes a multi-relay path, so requests are slower than a direct route.
