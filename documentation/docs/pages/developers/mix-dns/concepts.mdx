# Concepts & security

## Security model

`mix-dns` follows the shared [mixnet exit security model](/developers/concepts/exit-security). What differs from a plain browser DNS lookup:

| Segment | What's visible |
|---|---|
| Browser → entry gateway | Sphinx-encrypted UDP fragment over WebSocket. Entry gateway sees your IP, not the queried hostname. |
| Inside the mixnet | Sphinx layered encryption. Each node sees only its previous and next hop. |
| IPR → resolver | Plain UDP DNS query. The resolver sees the queried hostname and the IPR's IP. |
| Resolver → IPR → you | Plain UDP DNS response (also Sphinx-encrypted on the return mixnet legs). |

<Callout type="warning">
DNS is plaintext UDP at the resolver. The resolver knows what you're asking for; it does not know who is asking. To remove the resolver from your trust set, choose a resolver you already trust, or layer DNS-over-HTTPS via `mixFetch` to a DoH endpoint instead of using `mixDNS` directly.
</Callout>
