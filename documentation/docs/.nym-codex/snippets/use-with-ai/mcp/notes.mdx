## Notes on the MCP server [#notes]

- **Docs coverage.** `search_docs` indexes the public Nym developer and network documentation and the NymVPN client's docs. Answers cite the exact section, so you (or the agent) can open the source page and read it in full.
- **Index freshness.** The Nym docs and source are indexed again on each change to the development branch. The NymVPN client is indexed at each release, and its links point at that release's tag.
- **Live-data freshness.** The network tools query the Nym APIs on each call, so results are as current as those APIs. A tool that cannot reach its upstream returns the failure as a tool result (`isError: true`) and does not fail the MCP request, so the agent can read it and retry.
- **Read-only.** No tool can change network or chain state.
- **Retrieval granularity.** Ranking operates on whole sections, so the quality of an answer depends on the section behind it. See [How search works](snippet:nym/use-with-ai/mcp/how-search-works).
