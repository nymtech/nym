> The `nym-node` binary was built in the [building nym](snippet:nym/operators/binaries/building-nym/intro) section. If you haven't yet built Nym and want to run the code, go there first.

There are a couple of steps that need completing before starting to set up your `nym-node`:

1. **[Prepare your wallet](/operators/nodes/preliminary-steps/wallet-preparation):** [desktop](https://nym.com/wallet) or [CLI](/developers/tools/nym-cli/commands).
2. **[Requisition and setup a VPS](/operators/nodes/preliminary-steps/vps-setup)** (Virtual Private Server)

Make sure to follow these steps carefully as it prevents a lot of troubleshooting later on.
