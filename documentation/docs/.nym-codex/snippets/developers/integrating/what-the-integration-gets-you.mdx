## What the destination still sees [#what-the-integration-gets-you]

The destination stops seeing the user's IP address, for the endpoints you routed. It still sees request timing, request content, and any identifier your requests already carry. Traffic you could not route still shows the real address. When you describe the result, list what the destination still sees.
