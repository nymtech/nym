---
title: "anon-rpc: RPC privacy for wallets"
---

[anon-rpc](https://ethereum.github.io/anon-rpc/) is an Ethereum Foundation standard. A wallet runs an anonymising network's client as hash-pinned code in a sandbox, and the network supplies that client as a single worker bundle named on-chain by the keccak256 of its bytes. One integration on the wallet side covers every network that ships a conforming worker. The EF documents the protocol, the harness, and the capability API; this page covers only what Nym adds.

Nym ships a conforming worker that routes `fetch` and Ethereum RPC over the Nym mixnet, built on [mix-fetch](snippet:nym/developers/mix-fetch/intro). A wallet that already supports anon-rpc needs no Nym SDK: it points the EF harness at Nym's specifier address, and the harness fetches the bundle, checks its hash, and runs it sandboxed.
