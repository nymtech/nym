### Make executable and initialise [#reward-tracker-make-executable-and-initialise]

- In the directory where you have the program saved, run:
```sh
chmod u+x ./node_rewards_tracker.py

./node_rewards_tracker.py
```

The second command created a `/data` sub-directory:
```text
└── data
    └── wallet-addresses.csv
```

<Callout>
In case you see an error: `ModuleNotFoundError: No module named '...'` install these dependencies: 
```sh
python3 -m venv .venv && . .venv/bin/activate
pip install requests pyyaml tabulate colorama
# or
sudo apt install python3-requests python3-yaml python3-tabulate python3-colorama
```
</Callout>
