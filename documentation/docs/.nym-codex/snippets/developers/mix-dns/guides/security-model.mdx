## Security model [#security-model]

`mix-dns` follows the shared [mixnet exit security model](snippet:nym/network/infrastructure/exit-services/intro). The DoH request is a TLS session that the browser client opens against the resolver and terminates there. The mixnet carries it as encrypted TCP segments, and the IPR exit forwards them without terminating the TLS, so the exit reads only ciphertext. The resolver sees the queried hostname and the IPR's IP, never yours. Nothing between you and the resolver reads the hostname, the IPR included; only the resolver, which has to answer it, reads it. The default endpoints are IP-literal URLs, so no SNI hostname reaches an on-path observer either.

<Callout type="warning">
DoH encrypts the query in transit, but the resolver still decrypts and answers it, so it reads the hostname you are looking up, while the mixnet keeps it from learning who you are. Choosing one DoH endpoint over another only changes which third party sees the queries; all of them see them coming from the IPR. To remove the resolver from your trust set, pick one you already trust.
</Callout>
