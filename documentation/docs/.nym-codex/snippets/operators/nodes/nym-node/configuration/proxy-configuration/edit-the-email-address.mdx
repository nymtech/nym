#### Edit the email address [#edit-the-email-address]

If you used the template above - before you save and close the file, make sure to edit the email address:

- Change the email address you're willing to use for being contacted.
```html
<a href="mailto:<EMAIL>">maintainer</a>
```

- Additionally you can add your own favicon logo on the line:
```html
<link rel="icon" type="YOUR_FAVICON_IMAGE_PATH" href="">
```
