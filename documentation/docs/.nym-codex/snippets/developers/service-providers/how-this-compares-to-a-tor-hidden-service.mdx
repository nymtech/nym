## How this compares to a Tor Hidden Service [#how-this-compares-to-a-tor-hidden-service]

There are some similarities to a Tor Hidden Service, such as access only by Nym address (no clearnet IP/domain), and keeping traffic 'within' the Mixnet. There are however some key architectural differences which can be found in the [SURBs vs Tor HS](/network/deep-dives/hidden-services) doc.
