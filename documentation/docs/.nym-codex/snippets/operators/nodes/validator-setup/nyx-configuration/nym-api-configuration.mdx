### Nym API configuration [#nym-api-configuration]

```nginx
### To expose the nym-api webserver
server {
  listen 80;
  listen [::]:80;
  server_name "<NYM_API_HOSTNAME>";
  add_header 'Access-Control-Allow-Origin' '*';

  location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  }
}
```

- Followed by:

```sh
apt install certbot python3-certbot-nginx
certbot --nginx -m <EMAIL> --agree-tos
```

These commands get you an HTTPS encrypted nginx proxy in front of the endpoints.
