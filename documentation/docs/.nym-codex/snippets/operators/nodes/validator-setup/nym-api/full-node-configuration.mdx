## Full node configuration [#full-node-configuration]

To install a full node from scratch, refer to the [Nyx validator setup](snippet:nym/operators/nodes/validator-setup/nyx-validator/intro) and follow the steps there. Additionally, to ensure `nym-api` works as expected, confirm that [transaction indexing is on](snippet:nym/operators/nodes/validator-setup/nym-api/ensure-transaction-indexing-is-turned-on-in-configtoml) and that [pruning settings are manually configured](snippet:nym/operators/nodes/validator-setup/nym-api/ensure-pruning-settings-are-manually-configured).
